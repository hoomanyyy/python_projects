# Python Projects

A personal collection of Python scripts and mini-projects written while learning and experimenting. Each item is self-contained.

## Contents

| Path               | What it is                                             |
| ------------------ | ----------------------------------------------------- |
| `face-project/`    | Face detection / recognition experiment.              |
| `python_sentense/` | Text and sentence processing experiments.             |
| `try/`             | Scratch space for small experiments.                  |
| `bot3.py`          | Standalone bot script.                                 |
| `bot5.py`          | Standalone bot script.                                 |
| `caculate.py`      | Simple calculator utility.                             |
| `library.py`       | Small library / utility module.                        |

> The descriptions above are a starting point — update each row with the exact purpose of the script or folder.

## Requirements

- Python 3.9+

Some scripts need extra packages (for example the face project typically needs `opencv-python`). Install per-script as needed:

```bash
pip install <package>
```

## Usage

Run any script directly:

```bash
python bot3.py
python caculate.py
```

For the folders, open each one for its own files and entry point.

## Notes

- This is a learning repository; scripts are independent and can be run on their own.
- Consider adding a short comment header to each file describing what it does.
